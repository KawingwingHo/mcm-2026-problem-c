# Task 2 图表说明 (Figure Descriptions)

### 图表 1: 仿真框架图 (Simulation Framework)
- **文件名**: `wlcs_framework.svg`
- **内容**: 可视化展示了 **全赛季局部反事实仿真 (WLCS)** 框架。图表描绘了从数据重构（潜在粉丝强度估计）到平行宇宙模拟（反事实引擎），再到最终结果对比（百分比制 vs 排名制）的数据流向。
- **视觉效果**: 采用流程图形式，利用不同颜色区分输入、处理和输出阶段，清晰阐明了仿真方法论的逻辑递进关系。

### 图表 2: 潜在粉丝强度分布 (Latent Fan Strength Distribution)
- **文件名**: `latent_fan_strength_violin.svg`
- **内容**: 一幅 **增强型雨云图 (Annotated Raincloud Plot)**，展示了四个选手层级（冠军、顶层、中层、早期淘汰）的“潜在粉丝强度”分布。它结合了三层数据信息：
    1.  **半小提琴图 (顶部)**：展示密度分布形态，显示冠军组具有明显的右偏高强度分布。
    2.  **箱线图 (中部)**：标示中位数和四分位距 (IQR)，提供统计概括信息。
    3.  **抖动散点 (底部)**：绘制原始仿真数据点 (N > 400)，展示样本量的丰富度。
    4.  **显著性标注**: 标记了冠军组与顶层组之间的统计学显著差异 ($p < 0.001$)。
- **视觉效果**: 提供了从分布形态、集中趋势到原始样本的全方位视图，从统计学上证明了“潜在粉丝强度”是区分冠军的核心特征。

### 图表 3: 机制对比图 (Mechanism Comparison)
- **文件名**: `mechanism_comparison.svg`
- **内容**: 一幅双轴折线图，对比了 **百分比制** (红色曲线) 与 **排名制** (蓝色阶梯线) 对不同粉丝票数的数学响应。图表特意标注了一个“民粹主义区域” (粉色阴影区)，在此区域内，极端的粉丝票数在百分比制下持续影响结果，而在排名制下收益递减。
- **视觉效果**: 阶梯函数直观展示了排名制的“量级压缩”效应，阴影区域明确标识了排名制相对于百分比制线性敏感性的过滤范围，凸显了其对民粹噪声的抑制作用。

### 图表 4.1: 比赛演化热力图 - 百分比制 (Game Evolution Heatmap 1: Percentage Rule)
- **文件名**: `game_evolution_heatmap_1.svg`
- **内容**: 阐释了在百分比制下，评委评分分歧和粉丝投票差异组合下的“爆冷事件”概率。展示了由于粉丝投票影响力的无约束性，存在大面积的“高风险爆冷区”。
- **视觉效果**: 红色区域分布广泛，直观展示了传统赛制对民粹主义投票的脆弱性。

### 图表 4.2: 比赛演化热力图 - 排名制 (Game Evolution Heatmap 2: Rank Rule)
- **文件名**: `game_evolution_heatmap_2.svg`
- **内容**: 对应排名制下的演化模拟。由于排名制对分差进行了“量级压缩”和“界限限制”，爆冷事件被限制在对角线附近的合理范围内。
- **视觉效果**: 蓝色“安全区”明显扩大，体现了赛制在保护专业性（评分分歧较小时）方面的有效性。

### 图表 4.3: 演化博弈 3D 堆叠对比图 (3D Game Evolution Comparison)
- **文件名**: `game_evolution_3d_comparison.svg`
- **内容**: 将 **百分比制 (Red Mountain)** 与 **排名制 (Blue Plain)** 在同一 3D 空间中进行量化堆叠对比，反映了两套赛制在不同评分/投票分歧下的稳健性差异。
- **视觉效果**: 
    - **风格统一化**: 两套方案均采用相同的 **半透明渲染 ($\alpha=0.6$)** 和 **网格骨架 (Wireframe)**，确立了对称、专业的视觉对比基准。
    - **红色高山**: 展现了百分比制下爆冷风险的无界增长，峰值处呈现高饱和度深红强度，对应报告中 **22.5%** 的加权总体争议率。
    - **蓝色平原**: 展现了排名制对风险的有效压制与“削峰”效应，对应报告中 **15.2%** 的较低争议率。
    - **高度一致性**: 图中曲面高度与颜色深浅严格对应其右侧的指标条数值，直观论证了排名制对“风险体积”的大幅压缩效果。

### 图表 5: 专业相关性对比 (Skill Correlation Comparison)
- **文件名**: `skill_correlation_boxplot.svg`
- **内容**: 一幅箱线图，对比了三种情境下的 **专业相关性系数 ($\rho$)**：当前百分比制、纯排名制以及推荐方案 (排名制 + 评委二选一)。
- **视觉效果**: 展示了推荐方案 (Rank + Judge Save) 拥有最高的中位数相关性 ($\rho=0.9156$) 和最窄的四分位距 (最短的须状线)，表明该方案在奖励专业技能方面具有最强的鲁棒性和一致性。

### 图表 6: 争议过滤桑基图 (Controversy Filtration Sankey)
- **文件名**: `controversy_sankey.svg`
- **内容**: 一幅桑基图，追踪了“高风险淘汰事件”通过逐级过滤机制的流向。
    - **左侧**: 初始的高风险事件总数 (民粹风险, 22.5%)。
    - **中间**: 被排名制拦截的事件 (过滤掉 7.3%)。
    - **右侧**: 被 Judge Save 机制进一步拦截的残留事件 (再过滤 7.9%)，最终残留争议率为 7.3%。
- **视觉效果**: 利用流动的宽度和颜色渐变（红到绿/灰），直观可视化了“过滤过程”，展示了争议率从 22.5% 一步步降低至 7.3% 的演变路径。
