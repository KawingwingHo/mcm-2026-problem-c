# 2026 美赛 C 题项目

围绕《Dancing with the Stars》的评委评分、粉丝投票估计与投票机制分析，保存项目代码、数据、分析报告、图表及论文文档。

## 内容导航

| 路径 | 内容 |
| --- | --- |
| `数据预处理/` | 原始数据、清洗脚本与清洗结果 |
| `task1/` | 粉丝投票估计、评分效能分析及图表 |
| `task2/` | 赛制比较、争议案例分析及图表 |
| `task3/` | 选手特征与舞伴影响分析 |
| `task4/` | PADW 动态权重投票机制分析 |
| `sensitivity_analaysis/` | 敏感性分析代码、结果与报告（保留原目录拼写） |
| `2026_MCM_Problem_C.pdf` | C 题题目 |
| `2026_MCM-ICM_Problems (1)/` | 赛题及相关材料 |
| `final.docx`、其他 `.docx` 文件 | 论文与分任务文档 |
| 根目录 `.tex` 文件 | LaTeX 文稿与符号表 |

各任务的具体方法和已有结果见相应目录下的 Markdown 报告。压缩包保留为原始项目归档。

## 使用说明

本仓库保留上传时的项目目录结构。运行脚本前，请检查所需 Python 依赖、输入文件路径与工作目录；本次上传未验证完整计算流程的可复现性。

虚拟环境、缓存、系统文件和 Office 临时锁文件不纳入版本控制。
